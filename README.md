# AquaEarth Secure Login – Deployment Guide

## 📌 Overview
Secure login system for AquaEarth with Firebase + versioning.

## 🚀 Deployment
1. Extract files to server
2. Edit Firebase config in `home.js` if needed
3. Run locally: `npx http-server .`
4. Bump version: `node bump-version.js`
5. Commit & push:
   ```bash
   git add .
   git commit -m "Bump version"
   git push origin main
   ```
